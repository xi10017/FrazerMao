# Preview Project

Follow these steps to start the development server and preview the MuPractice project.

1.  **Start Dev Server**:
    ```bash
    npm run dev
    ```

2.  **Open Preview**:
    Open [http://localhost:3000](http://localhost:3000) (or the port specified in the terminal) in your browser.
